приложение "Список сотрудников".
Функционал
1) меню Главная - получить весь список сотрудников
2)  Редактирование - получить сотрудника для редактирование строки из списка Сотрудников
3)  Просмотр - получить сотрудника для просмотра строки из списка Сотрудников
4)  Дерево - перечень параметров для поиска по Списку сотрудников
5)  Данные  список сотрудников формируются из интерактивного файла в формате JSON
6)  В приложении 3 окна: Главное и 2 модальных.
